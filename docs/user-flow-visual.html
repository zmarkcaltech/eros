✨ Available Features from Dashboard

💬

Conflict Chat

3-way real-time conversation with AI mediator using Emotionally Focused Therapy. Partner A + Partner B + AI work through conflicts together.

🗺️

MapQuest for Couples

Interactive game with 3 modes (Discovery/Growth/Intimacy) and 3 depths. Guess → Answer → Rate → Reflect cycle to learn about each other.

📸

Photo Gallery

Upload couple photos, add captions, and set a favorite photo to display on your dashboard. Build your visual relationship timeline.

👤

Profile Management

Edit your personal information, upload avatar, update relationship details, and manage account settings.

🛠️

Dev Chat Simulator

Testing tool to create simulated conversations with custom personalities, scenarios, and communication styles for AI evaluation.
